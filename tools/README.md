## carve-keyframes.mjs

トップページのヒーローで、大見出しを「削り出す」演出に使う `@keyframes` を生成するスクリプトです。

大見出しを上から N 段に分け、1段ごとに左→右、次の段は右→左…と、工具が往復するように見える範囲を広げます。生成するのは次の2つです。

- `carve-pass`：大見出しの切り抜き（`clip-path: polygon()`）
- `carve-tip`：刃先の光る線の位置（`carve-pass` と同じタイミングで動く）

Node.js（v18 以降）があれば動きます。追加のインストールは必要ありません。

### 段数を変える

```sh
# 生成結果を画面に表示するだけ（ファイルは変わらない）
node tools/carve-keyframes.mjs --passes 12

# css/style.css の目印の間を書き換える
node tools/carve-keyframes.mjs --passes 12 --write
```

- `--passes` を省略すると 8 段になります（1〜40 の範囲で指定できます）。
- 書き換えるのは、`css/style.css` の中の `/* carve-keyframes:start */` から `/* carve-keyframes:end */` までです。この範囲は手で編集せず、スクリプトで作り直してください。

### 速さを変える

速さは生成した `@keyframes` ではなく、`css/style.css` の `.hero` に書いた変数で調整します。

| 変数 | 意味 | 初期値 |
|---|---|---|
| `--carve-delay` | ページを開いてから削り始めるまでの待ち時間 | `0.3s` |
| `--carve-pass-duration` | 全段を削り終えるまでの時間 | `1.6s` |
| `--carve-finish-duration` | 削り跡の細い線が埋まり、くっきり完成するまでの時間 | `0.5s` |

演出全体の長さは、この3つの合計（初期値では 2.4 秒）です。

段数を増やしても `--carve-pass-duration` が同じなら、全体の時間は変わらず、1段あたりが速くなります。

## ogp.html

SNS でURLを共有したときに表示される画像（`images/ogp.png`、1200×630px）の元になる HTML です。公開するページではありません。

文字を画像編集ソフトで置くかわりに HTML で組んでいるので、文言や配置を変えたいときは、この HTML を直して撮り直します。

- フォントはサイトと同じ Google Fonts（Six Caps・Noto Sans JP）を読み込むので、撮影するときはインターネットにつながっている必要があります。
- 色は `css/style.css` と同じ値です。サイトの色を変えたときは、`ogp.html` の `:root` もあわせて直してください。
- SNS によっては画像の端が切れて表示されるので、文字は `--safe-x`（左右 80px）・`--safe-y`（上下 60px）の内側に収めています。

### 作り直す

Google Chrome だけでできます。追加のインストールは必要ありません。

1. `tools/ogp.html` を Chrome で開く
2. デベロッパーツールを開く（Mac は `⌘ + ⌥ + I`）
3. デバイスツールバーを表示する（`⌘ + ⇧ + M`）
4. 画面上部の大きさの欄に `1200` と `630` を入れ、倍率（DPR）を `1.0` にする
   - DPR は、右上の「︙」メニューの「デバイスピクセル比を追加」で表示される欄で指定します。
5. コマンドメニューを開き（`⌘ + ⇧ + P`）、「スクリーンショットをキャプチャ」（Capture screenshot）を実行する
6. 保存された PNG を `images/ogp.png` に置き換える（ファイル名を変えると、各ページの `og:image` も直す必要があります）

保存した画像が 1200×630px になっているか確認してください。DPR が 2 のままだと 2400×1260px になります。
