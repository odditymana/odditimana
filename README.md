# ODDITIMANA

安部知樹（KAZUKI ABE）のポートフォリオサイトのソースコードです。

- 公開予定：https://odditimana.com/

## 見どころ

- ヒーローの「削り出し」演出を、JavaScript を使わず CSS だけで実装
- Lighthouse でアクセシビリティ・ベストプラクティスが全ページ 100 点
- Claude Code を使い、判断は自分・実装は AI・確認は自分という分担で制作

## 概要

- Webサイト4件・フライヤー5件の作品と、プロフィールを掲載しています。
- ページ構成：トップ / ABOUT / 作品詳細（4ページ） / 404

## 技術

- HTML・CSS・JavaScript のバニラ構成（フレームワーク・ビルドツールなし）
- CSS は1ファイル（`css/style.css`）。色・フォント・余白は `:root` の CSS 変数で管理しています。
- JavaScript は1ファイル（`js/main.js`）。スマホのメニューと、画像の拡大表示（ライトボックス）だけを担当しています。
- 画像は WebP。元画像はリポジトリに含めていません。

## 工夫した点

### ヒーローの「削り出し」演出

トップの大見出し「WEB DESIGN & CODING」を、工具で削り出すように表示する演出です。JavaScript を使わず、CSS だけで作っています。

- `clip-path` で、見える範囲を上の段から左右に往復させながら広げます。
- `mask-image` の細い横縞で、削った跡のように見せます。
- 最後に、`@property` で登録した変数（`--carve-line`）を動かして横縞の隙間を埋め、くっきりした文字に仕上げます。
- 往復の動きの `@keyframes` は、`tools/carve-keyframes.mjs` で生成しています。段数を変えて作り直せます（使い方は `tools/README.md`）。

### ライトボックス

フライヤーと、作品詳細ページの画面キャプチャを拡大表示します。

- HTML の `<dialog>` 要素の `showModal()` で作っています。
- 閉じるボタン、背景のクリック、Esc キーのどれでも閉じられます。
- 閉じたら、開く前に押したボタンにフォーカスを戻します。
- 縦に長いキャプチャは、横幅に合わせて表示し、縦にスクロールして全体を見られるようにしています。

### アクセシビリティ

- **動きを減らす設定（`prefers-reduced-motion`）**：削り出しの演出を行わず、最初から完成した見出しを表示します。画像の拡大の動きも行わず、切り替えの動きは短くしています。
- **キーボード操作**：リンクやボタンは、ホバーとキーボードフォーカスで同じ見た目になるようにしています。黒い背景の上では、フォーカスの枠の色を背景に合わせて変えています。
- **スマホのメニュー**：`aria-expanded` で開閉の状態を伝え、Esc キーで閉じたときはメニューのボタンにフォーカスを戻します。
- **読み上げへの配慮**：画像の代替テキスト、拡大ボタンの `aria-label`、ナビの `aria-current` を設定しています。番号の飾り（①②③）は `aria-hidden` にして、順番は `ol` で伝えています。

### 表示速度

- **Six Caps の自前配信**
  - 見出し用のフォント Six Caps は、Google Fonts の配布元から、サイトで使う基本的な欧文の範囲（latin）の woff2 だけを取得し、自分のサーバーから `preload` で読み込んでいます。和文の Noto Sans JP は Google Fonts から読み込んでいます。
  - `font-display` は `block` にしています。届くまで文字を透明にして待つ指定です。代わりのフォントから Six Caps に切り替わるときに大見出しの大きさが変わり、レイアウトがずれるのを防ぐためです。大見出しは削り出しの演出で最初は見えていないので、待つ間が透明でも違和感がありません。
- **画像**：表示サイズに合わせた小さいサイズを用意し、`srcset` と `sizes` で切り替えています。
- **優先読み込み**：作品詳細ページのヒーロー画像に `fetchpriority="high"` を付けています。

| 項目 | 点数 |
|---|---|
| パフォーマンス | 95〜100 |

## フォルダ構成（主なもの）

```
.
├── index.html         トップ（作品一覧）
├── about/             プロフィール
├── works/             作品詳細（作品ごとのフォルダ）
├── 404.html           存在しない URL で表示するページ
├── css/style.css      全ページ共通の CSS
├── js/main.js         メニューとライトボックス
├── fonts/             Six Caps とライセンス（OFL.txt）
├── images/            画像（WebP）、OGP 画像
├── tools/             削り出し演出の keyframes 生成スクリプト、OGP 画像の元の HTML
├── favicon.svg
├── apple-touch-icon.png
└── CLAUDE.md          作業ルール
```

## 手元での確認方法

簡易サーバーを立てて、ブラウザで開きます。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

- `404.html` は、どの深さの URL で表示されても崩れないよう、CSS・画像・リンクのパスを `/` から始まるルート相対パスで書いています。ファイルを直接開くと崩れるので、`http://localhost:8000/404.html` のようにサーバー経由で確認してください。
- 存在しない URL で `404.html` を表示する設定は、公開先のサーバー側で行います。
